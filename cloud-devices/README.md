# Nox Remote AI v0.9 Cloud Devices

Prototype only. The Cloud Devices API uses PostgreSQL and requires a separate HTTPS cloud host; GitHub Pages does **not** host databases or dynamic APIs. Device enrollment requires explicit consent and a single-use pairing code. Do not publish secrets or enable unauthenticated remote control.

The complete source package is available in the project conversation. Cloud deployment, security hardening, compilation and WPF integration remain pending.
